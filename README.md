# Martian Robots

Implementation of the Red Badger Martian Robots programming challenge.

The program simulates robots moving around a bounded rectangular grid. Each robot receives a starting position, orientation, and sequence of instructions.

Robots that move beyond the boundary of the grid are considered lost. A lost robot leaves a scent at its last valid position, preventing subsequent robots from being lost from the same grid point.

## Requirements

- Node.js 20+
- npm
